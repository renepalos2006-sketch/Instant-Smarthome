# Components

## Central Unit/Lamp

- ESP32-S3
- BH1750 (Lichtsensor)
- EKMB (Bewegungssensor)
- SCD40 (CO2 Sensor)

## Control Unit

- Display
- Rotary Encoder
- Buttons
- BME280 (Temperatur, Luftdruck, Luftfeuchtigkeit)

## External Components

- Shelly BLU Door/Window (Window Contact) 5x
- Wireless Lightswitch
- Shelly BLU TRV (Heizkörperthermostat)
